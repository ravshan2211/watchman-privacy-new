3. Nimalar yig'ilmaydi

  • Telefoningizning joylashuvi (GPS), kontaktlar, fotosuratlar, fayllar va SMS.
  • Barmoq izi: u faqat telefonning o'zida, Android tizimi tomonidan tekshiriladi. Ilova va server uni ko'rmaydi.

4. Ma'lumotlar qanday himoyalanadi

  • Telefon, server va avtomobil qurilmasi o'rtasidagi aloqa TLS (wss://) orqali shifrlanadi.
  • Serverda parollar va ID faqat bcrypt xesh ko'rinishida saqlanadi. Server jurnallarida (log) parollar, ID va WiFi paroli yashiriladi.
  • Noto'g'ri parol ko'p marta kiritilsa, hisobga kirish vaqtincha bloklanadi.

5. Ma'lumotlarni boshqalarga berish

Ma'lumotlar sotilmaydi va reklama uchun uzatilmaydi. Server Render (render.com) xosting xizmatida ishlaydi. U ma'lumotlarni faqat serverni ishlatish uchun saqlaydi. Qonun talab qilgan hollardan tashqari ma'lumotlar uchinchi shaxslarga berilmaydi.

Avtomobil joyini aniqlash uchun atrofdagi Wi-Fi tarmoqlar ro'yxati (hisob, login yoki boshqa shaxsiy ma'lumotlarsiz) geolokatsiya xizmati BeaconDB (beacondb.net) ga, u joyni topa olmasa Google Geolocation API ga yuboriladi. Ilovadagi xarita OpenStreetMap orqali ko'rsatiladi.

Эта политика объясняет, какие данные собирают приложение WATCHMAN (пакет: uz.ravshan2211.watchman) и подключённое к нему автомобильное устройство, для чего они используются, где хранятся и как их удалить.

1. Что делает приложение

WATCHMAN используется для удалённого управления автомобилем через установленное в нём устройство: закрытие и открытие дверей, дистанционный запуск двигателя, режим охраны и оповещения. Телефон и устройство связываются друг с другом через сервер приложения.

3. Что не собирается

  • Местоположение вашего телефона (GPS), контакты, фотографии, файлы и SMS.
  • Отпечаток пальца: он проверяется только на самом телефоне системой Android. Приложение и сервер его не видят.
  • В приложении нет рекламы, аналитики и сервисов отслеживания.

4. Как защищены данные

  • Связь между телефоном, сервером и автомобильным устройством шифруется по TLS (wss://).
  • На сервере пароли и ID хранятся только в виде хеша bcrypt. В журналах сервера пароли, ID и пароль WiFi скрываются.
  • При многократном вводе неверного пароля вход временно блокируется.

5. Передача данных третьим лицам

Данные не продаются и не передаются для рекламы. Сервер работает на хостинге Render (render.com), который хранит данные только для работы сервера. Кроме случаев, предусмотренных законом, данные третьим лицам не передаются.

Для определения местоположения автомобиля список окружающих сетей Wi-Fi (без учётной записи, логина и других личных данных) отправляется в сервис геолокации BeaconDB (beacondb.net), а если он не нашёл место — в Google Geolocation API. Карта в приложении отображается через OpenStreetMap.

6. Разрешения

  • Интернет и состояние сети: для связи с сервером.
  • Уведомления: для показа оповещений охраны.
  • Фоновая служба и запуск при включении телефона: чтобы получать оповещения, даже когда приложение закрыто.
  • Исключение из оптимизации батареи: чтобы телефон не задерживал оповещения.
  • Отпечаток пальца: для защиты входа в приложение (необязательно).
  • Вибрация: для сигнала оповещения.

7. Срок хранения данных и удаление учётной записи WATCHMAN

Данные учётной записи хранятся, пока существует учётная запись. История событий ограничена последними 300 записями на учётную запись.

Как запросить удаление учётной записи WATCHMAN:

  1. Напишите на aslida.noshqacha@gmail.com с темой «Удаление учётной записи WATCHMAN».
  2. Укажите в письме логин вашей учётной записи.
  3. Мы ответим письмом, чтобы подтвердить, что вы владелец учётной записи (например, попросим ID из приложения).
  4. После подтверждения учётная запись удаляется в течение 30 дней, и мы сообщаем вам об этом.

Что удаляется: логин, хеши пароля и ID, история событий, последнее определённое местоположение, список подключённых телефонов (идентификатор, модель, время) и недоставленные оповещения. Что сохраняется: ничего; только в технических резервных копиях хостинга данные могут оставаться до 30 дней.

Удаление только данных без удаления учётной записи: напишите на тот же адрес с темой «Удаление данных WATCHMAN», укажите логин и какие данные нужно удалить (история событий, последнее местоположение, список подключённых телефонов). После подтверждения владения в течение 30 дней удаляются только эти данные, а учётная запись продолжает работать. Подключённые телефоны можно удалить и в самом приложении: Настройки → «Qurilmalar».

Данные на телефоне удаляются при удалении приложения с телефона.
